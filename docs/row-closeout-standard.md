# Row-by-row takeoff delivery standard

Apply this standard to every subsequent row. It is a review/delivery procedure, not a claim that the production pipeline already performs all steps automatically.

1. Identify the physical component, material and location. Exclude legends, duplicate views and multiple edges of the same object from counts.
2. Trace plan, elevation and detail with source IDs and entity evidence. Record an audited not-applicable disposition only when justified; missing is not none.
3. Bind dimension roles, units, start/end boundaries, openings and physical multipliers. Use the correct area, linear or assembly basis for that component, not a universal formula.
4. Calculate from CAD evidence and freeze results before the comparison stage. Previously seen samples remain development samples; do not call them blind tests.
5. Compare each required field under the unchanged versioned acceptance policy. Preserve human source values and keep reviewed label corrections in a separate audited layer.
6. Embed component-specific original CAD locator and readable detail images in the workbook. Preserve image bytes, aspect ratio and source hashes. Re-render vectors when raster evidence is unreadable; do not redraw or upscale evidence.
7. Verify formulas, missing/zero inputs, input changes, image objects and source integrity. Append completed rows to a cumulative deliverable and keep unresolved rows visible.

Report numeric agreement, reviewed full-row completion, automatic full-row completion and remaining coverage separately. Missing prices outside the evaluation scope do not invalidate a correct takeoff, but a takeoff is not a priced commercial quotation. One reviewed sample does not prove project-level accuracy.

Keep every reference row and stable identity in the work queue. Preserve prior research. Document a difficult row's specific gap and proceed to other rows when appropriate; never remove hard rows, fill missing dimensions with zero or copy target values to increase the score.

Extract reusable rules and counterexamples from completed rows. Private drawings, workbooks, images, identifiers, measured values and customer-specific rules must not enter public releases.
